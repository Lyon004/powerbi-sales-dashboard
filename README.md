#  Retail Sales Performance Dashboard

![Retail Sales Dashboard](retail-sales-dashboard.png)

##  Project Overview
This project analyzes retail sales data to uncover key business insights, including revenue trends, customer spending behavior, and product performance.  

Using **PostgreSQL** for data modeling and **Power BI** for visualization, the project demonstrates how raw transactional data can be transformed into actionable insights for decision-making.

---

##  Objectives
- Analyze total revenue generated by the business  
- Identify top-performing products  
- Understand customer spending patterns  
- Track monthly sales trends  

---

##  Dataset Structure

The project is based on three relational tables:

### 1. Customers
- `customer_id` (Primary Key)  
- `name`  
- `country`  

### 2. Orders
- `order_id` (Primary Key)  
- `customer_id` (Foreign Key)  
- `order_date`  

### 3. Order Items
- `order_id` (Foreign Key)  
- `product`  
- `quantity`  
- `price`  

---

##  SQL Data Modeling

### Create Tables
```sql
CREATE TABLE customers (
    customer_id INT PRIMARY KEY,
    name VARCHAR(50),
    country VARCHAR(50)
);

CREATE TABLE orders (
    order_id INT PRIMARY KEY,
    customer_id INT,
    order_date DATE,
    FOREIGN KEY (customer_id) REFERENCES customers(customer_id)
);

CREATE TABLE order_items (
    order_id INT,
    product VARCHAR(50),
    quantity INT,
    price DECIMAL(10,2),
    FOREIGN KEY (order_id) REFERENCES orders(order_id)
);
